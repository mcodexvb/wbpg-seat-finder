# WB PG Seat Finder — WBMCC 2026 Round 2

Static offline-capable seat matrix explorer for West Bengal PG medical counselling. Search by college, subject, course, quota, category, and institution type.

## Deployment

This repository is intended for Cloudflare Pages (production branch `main`). Static HTML/CSS/JavaScript; no build command. Upload the six files from `WB_PG_Seat_Finder_GitHub_Cloudflare_Ready.zip` to the repository root: `index.html`, `style.css`, `app.js`, `data.js`, `README.txt`, and `DEPLOY.md`.

The seat matrix is dated 21 November 2026. Verify with official WBMCC updates before making counselling decisions.
